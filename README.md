# Personal Academic Website

A clean, minimalist academic portfolio built with Jekyll.

## Local Development

1. Install dependencies:
   ```bash
   bundle install
   ```

2. Build and preview locally:
   ```bash
   bundle exec jekyll serve
   ```
   Open `http://localhost:4000` in your browser.

## Customization

- **Site & Contact Info:** Edit `_config.yml` and `_data/socials.yml`
- **Biography & Photo:** Edit `_pages/about.md` and replace `assets/img/prof_pic.jpg`
- **Publications:** Add your BibTeX entries to `_bibliography/papers.bib`
- **Projects:** Add or edit project files in `_projects/`
- **CV:** Update `_pages/cv.md` or place your CV PDF in `assets/pdf/`
